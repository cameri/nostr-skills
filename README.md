# Nostr Skills

A collection of skills for working with the Nostr protocol.

## Available Skills

- [nostr](skills/nostr/SKILL.md) - Core Nostr protocol skills and concepts
- [nak](skills/nak/SKILL.md) - Nostr Army Knife CLI tool for querying, publishing, and managing Nostr events
- [ngit](skills/ngit/SKILL.md) - Manage Git repositories using Nostr for decentralized coordination

## Contributing

To add a new skill, create a directory under `skills/` with a `SKILL.md` file including frontmatter for name, description, and license.
